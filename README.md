# AIdesigner · ЭОМ (прототип)

Браузерный прототип ИИ-помощника для проектирования электрики квартир:
загрузили план и спецификацию → система разложила точки по помещениям →
инженер двигает их мышью → группы, автоматы, сечения, длины кабелей,
потери напряжения и однолинейная схема пересчитываются сразу.

## Онлайн

После каждого пуша в `main` прототип собирается и выкладывается на GitHub Pages:
https://retoplerdaf.github.io/AIdesigner/
(один раз нужно включить: Settings → Pages → Source: GitHub Actions).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тесты расчётного движка
npm run build    # статическая сборка в dist/
```

## Как пользоваться

1. **Демо-квартира** открывается сразу. Для своего объекта нажмите «Новый».
2. **План**: загрузите картинку плана (PNG/JPG), кликните две точки известного размера и введите
   реальную длину в мм. Затем нажмите «Анализ» (OpenCV.js, библиотека грузится при первом нажатии).
   Сначала находится граница дома: проверьте синюю линию, при необходимости подтяните углы и стены
   и нажмите «Граница верна». Комнаты ищутся только внутри границы, поэтому панорамные окна им не мешают. Не найденные комнаты обведите прямоугольником или многоугольником
   (клик по углам), контуры поправьте инструментом «Растянуть»: угол растягивает комнату в две стороны,
   стена — в одну; чтобы убрать угол, нажмите на него и на красный «×» рядом (или Delete). Названия и площади
   с подписей на плане читаются автоматически (Tesseract.js, русский язык). Площадь с подписи служит проверкой:
   если контур с ней расходится больше чем на 2 %, план распознаётся заново с другой очисткой линий и проёмов,
   и берётся контур, ближайший к подписи. Косые стены (скосы, эркеры, перегородки под углом) поддерживаются,
   проёмы в них закрываются так же, как в прямых.
   Фокус в поле названия или площади подсвечивает на плане голубой рамкой, откуда оно взято; палочка рядом
   с полем — обвести подпись на плане вручную и прочитать только её.
3. **Спецификация**: если её нет, нажмите «Сгенерировать по помещениям»: каждое помещение получит типовой набор
   своего типа (свет, выключатель, розетки, техника) и сразу разложится по плану. Наборы правятся кнопкой
   «Типовые наборы…»: количество задаётся числом, по площади или по периметру, розетки можно ставить по углам.
   Наборы можно взять из текущего или сохранённого объекта (средние количества по помещениям каждого типа)
   и выгрузить в файл; хранятся в браузере. Либо загрузите Excel/CSV или вставьте строки из Excel
   (наименование, количество, мощность, помещение). Проверьте распознанные типы и нажмите
   «Разложить по плану».
4. Выключатели ставятся сами в каждое помещение со светом (если их нет в спецификации), а в каждой группе на каждое помещение появляется распределительная коробка: трасса идёт щит → коробки → точки. Между помещениями кабели идут только через проходные отверстия. Отверстие — позиция спецификации без нагрузки: раскладка ставит их на нужные стены, на плане это чёрная метка с числом кабелей. Его можно перетащить на любую стену между помещениями, удалить или добавить из списка; если между помещениями отверстия нет, группа получает предупреждение. В «Кабельном журнале» есть таблица проходов с ориентировочным диаметром гильзы.
5. Перетаскивайте точки, коробки, проходы в стенах и щит. Клик по точке или группе показывает расчёт с формулами
   и ссылками на нормы. Группу точки можно переназначить вручную.
6. Справа: таблица групп, однолинейная схема, кабельный журнал. «Экспорт CSV» и «Сохранить» (JSON).

## Устройство

```
src/engine/      чистый TypeScript без зависимостей от UI
  types.ts       модель проекта (мм, Вт)
  norms.ts       таблицы и справочники с указанием источника
  classify.ts    разбор спецификации (сейчас правила; место для LLM)
  placement.ts   распределение по помещениям и расстановка на плане
  presets.ts     типовые наборы по типам помещений и генерация спецификации из них
  roomDetect.ts  распознавание помещений на картинке плана (OpenCV)
  roomEdit.ts    правка контура: углы, стены
  roomLabels.ts  разбор подписей помещений (название, тип, площадь) из распознанного текста
  calc.ts        группы, токи, автоматы, сечения, ΔU, петля «фаза–нуль», ввод
  engine.test.ts тесты
src/ui/          редактор плана (SVG), панели, результаты
src/data/demo.ts демо-квартира и пример спецификации
```

Главный принцип: ИИ только разбирает вход и предлагает расстановку, а всё, что идёт
в расчёт и документацию, считает детерминированный код, и у каждого числа есть обоснование.

## Ограничения прототипа

- Распознавание спецификации по ключевым словам. Следующий шаг — LLM за тем же интерфейсом.
- Распознавание помещений — классическое компьютерное зрение: хорошо работает на чистых планах
  со сплошными стенами, хуже на сканах со штриховкой. Внутренние проёмы шире 2,4 м не закрываются,
  такие комнаты сливаются; разделите их вручную. Подписи, перечёркнутые линиями мебели или дугами дверей, читаются
  не всегда — их можно прочитать палочкой или ввести руками. DXF и векторный PDF пока не поддерживаются.
- Таблица допустимых токов — одна (ПУЭ табл. 1.3.6, трёхжильный медный кабель в воздухе),
  без поправочных коэффициентов на прокладку и группировку.
- Коэффициент спроса на вводе задаётся вручную, а не по СП 256.
- Слаботочка и выпуск чертежей в DWG/PDF по ГОСТ не реализованы.
- Общие стены ищутся только у помещений со стенами, параллельными осям; наружные стены и стояки не учитываются.
- Выключатель питается от коробки помещения вместе со светильниками; отдельные жилы «фаза до выключателя» не моделируются.
- Нормативные значения должен проверить проектировщик перед любым реальным применением.
