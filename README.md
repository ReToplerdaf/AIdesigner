# AIdesigner · ЭОМ (прототип)

Браузерный прототип ИИ-помощника для проектирования электрики квартир:
загрузили план и спецификацию → система разложила точки по помещениям →
инженер двигает их мышью → группы, автоматы, сечения, длины кабелей,
потери напряжения и однолинейная схема пересчитываются сразу.

## Онлайн

После каждого пуша в `main` прототип собирается и выкладывается на GitHub Pages:
https://retoplerdaf.github.io/AIdesigner/
(один раз нужно включить: Settings → Pages → Source: GitHub Actions).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тесты расчётного движка
npm run build    # статическая сборка в dist/
```

## Как пользоваться

1. **Демо-квартира** открывается сразу. Для своего объекта нажмите «Новый».
2. **План**: загрузите картинку плана (PNG/JPG), кликните две точки известного размера и введите
   реальную длину в мм. Затем инструментом «Помещение» обведите комнаты и задайте их названия и типы.
3. **Спецификация**: загрузите Excel/CSV или вставьте строки из Excel
   (наименование, количество, мощность, помещение). Проверьте распознанные типы и нажмите
   «Разложить по плану».
4. Выключатели ставятся сами в каждое помещение со светом (если их нет в спецификации), а в каждой группе на каждое помещение появляется распределительная коробка: трасса идёт щит → коробки → точки. Между помещениями все кабели идут через одно общее отверстие в стене; на плане это чёрная метка с числом кабелей, её можно двигать вдоль стены. В «Кабельном журнале» есть таблица проходов с ориентировочным диаметром гильзы.
5. Перетаскивайте точки, коробки, проходы в стенах и щит. Клик по точке или группе показывает расчёт с формулами
   и ссылками на нормы. Группу точки можно переназначить вручную.
6. Справа: таблица групп, однолинейная схема, кабельный журнал. «Экспорт CSV» и «Сохранить» (JSON).

## Устройство

```
src/engine/      чистый TypeScript без зависимостей от UI
  types.ts       модель проекта (мм, Вт)
  norms.ts       таблицы и справочники с указанием источника
  classify.ts    разбор спецификации (сейчас правила; место для LLM)
  placement.ts   распределение по помещениям и расстановка на плане
  calc.ts        группы, токи, автоматы, сечения, ΔU, петля «фаза–нуль», ввод
  engine.test.ts тесты
src/ui/          редактор плана (SVG), панели, результаты
src/data/demo.ts демо-квартира и пример спецификации
```

Главный принцип: ИИ только разбирает вход и предлагает расстановку, а всё, что идёт
в расчёт и документацию, считает детерминированный код, и у каждого числа есть обоснование.

## Ограничения прототипа

- Распознавание спецификации по ключевым словам. Следующий шаг — LLM за тем же интерфейсом.
- Помещения обводятся вручную прямоугольниками; распознавания стен из DXF/PDF пока нет.
- Таблица допустимых токов — одна (ПУЭ табл. 1.3.6, трёхжильный медный кабель в воздухе),
  без поправочных коэффициентов на прокладку и группировку.
- Коэффициент спроса на вводе задаётся вручную, а не по СП 256.
- Слаботочка и выпуск чертежей в DWG/PDF по ГОСТ не реализованы.
- Общие стены ищутся только у помещений со стенами, параллельными осям; наружные стены и стояки не учитываются.
- Выключатель питается от коробки помещения вместе со светильниками; отдельные жилы «фаза до выключателя» не моделируются.
- Нормативные значения должен проверить проектировщик перед любым реальным применением.
